חמישה דברים, בסדר הזה

זה התהליך משיעור 6, בגדול: תדריך, בנייה, בדיקה, תיקון, שמירה. הפעם על הדף האמיתי שלך, ובסוף הוא גם עולה לאוויר.

  • תדריך: מטרה אחת, קהל אחד, פעולה אחת. Claude מראיין, אתה עונה.
  • בנייה: Claude Code כותב את הדף, ואתה רואה אותו מיד בדפדפן.

אם בשיעור 7 החלטנו לתקן את האתר הקיים: אותו תהליך בדיוק, רק שהבנייה היא עריכה של עמודים קיימים, והשמירה היא דרך הניהול של האתר. נתאים בשיעור.

חלק 4 · תיאוריה

GitHub Pages: מה עולה, ומה לא

GitHub שומר את הקבצים ואת כל הגרסאות שלהם. Pages הופך אותם לאתר בקישור ציבורי, בחינם. אבל בחשבון החינמי המאגר ציבורי: כל אחד יכול לראות את כל הקבצים במאגר, לא רק את הדף.

עולה
  • הקובץ index.html
  • תמונות שיש לך זכות עליהן, מכווצות
  • רק מה שבתיקייה site
לא עולה, אף פעם
  • מפתחות (API Keys) וסיסמאות
  • פרטי מטופלים, בשום צורה
  • התדריך, דוח המצב, טיוטות וקבצי הסוכן
  • כל מסמך פנימי

הכלל: מה שלא היית תולה על הדלת של הקליניקה, לא נכנס לתיקייה site. בגלל זה הדף בתיקייה נפרדת, וכל השאר נשאר בחוץ.

מה קורה על המסך10 דקות

  • בקשה שלא מבינים? לא מאשרים. שואלים: "מה הפעולה הזו עושה?"

אחר כך בדוק שבתיקייה site יש רק מה שצריך לעלות לאוויר. אם יש שם משהו אחר, תגיד לי ואל תעלה אותו.
פתח מהתיקייה site מאגר חדש וציבורי ב-GitHub בשם [שם-המאגר], העלה אותו, והפעל GitHub Pages.

  • שם המאגר באנגלית, בלי רווחים. הוא יופיע בקישור, אז בוחרים משהו קריא
