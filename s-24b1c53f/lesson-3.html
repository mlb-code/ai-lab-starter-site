  • איך היה השבוע: הגרסה המודרנית והתמונה בהירו. ומה קרה לגרסה הקודמת.
  • גיבוי לפני שנוגעים: עותק של האתר, בבקשה אחת. מעכשיו, לפני כל שינוי גדול.
  • קובץ, שרת, כתובת: תזכורת של שלושת השלבים, ומה זה GitHub Pages. 5 דקות תיאוריה.
  • מעלים לאוויר: Claude Code פותח מאגר, מעלה, ומחזיר קישור. אתה מאשר כל צעד.
  • בודקים בטלפון, ולומדים לעדכן: שינוי קטן, ו"תעלה את הגרסה החדשה". נוהל של שלוש שורות.

לפני שמתחילים: סוגרים חלונות וטאבים מיותרים. משאירים פתוחים רק Cursor וכרום. המחשב יודה לך, והשיעור ירוץ חלק.

Claude Code כותב ישר על הקובץ. כשאתה מבקש "תבנה מחדש", הגרסה הקודמת נעלמת, אלא אם ביקשת עותק קודם. אחרי שהאתר באוויר, GitHub שומר כל גרסה שהעלית, ואפשר לחזור אחורה.

שתי המילים של היום: גיבוי (עותק של התיקייה, במחשב שלך) ו-גרסה (כל העלאה ל-GitHub נשמרת עם תאריך).

קובץ, שרת, כתובת: איפה אנחנו היום

בשיעור הקודם ציירנו שלושה שלבים. היום קופצים מהראשון ישר לשלישי, עם כלי אחד שעושה את זה בחינם.

השלבמה זהמי רואהאיפה אנחנו
קובץ מקומיקובץ HTML בתיקייה במחשב. בכרום רואים נתיב, לא כתובתרק אתה, מהמחשב הזהכאן היינו עד היום

GitHub Pages: GitHub שומר את הקבצים שלך ואת כל הגרסאות שלהם ("מאגר"). Pages הופך את המאגר לאתר בכתובת ציבורית, בחינם. הכתובת נראית כך: שם-המשתמש.github.io/שם-המאגר. בהמשך אפשר לחבר כתובת משלך.

בחשבון החינמי המאגר ציבורי. כל אחד יכול לפתוח ולראות את כל הקבצים שבו, לא רק את העמוד. לכן מעלים תיקייה אחת, של האתר בלבד.

לא עולה, אף פעם
  • תיקיית Mickey AI Cursor כולה, או תיקיית "גיבויים"
  • CLAUDE.md וכל קובץ הוראות או טיוטה
  • פרטים של מטופלים, בשום צורה
  • סיסמאות ומפתחות

הכלל: מה שלא היית תולה על דלת המרפאה, לא נכנס לתיקיית האתר. לכן הבקשה בשקף הבא מתחילה בבדיקה מה יש בתיקייה.

חלק 4 · טלפון

עכשיו באמת בטלפון, ואז בכרום

האתר באוויר, אז בודקים אותו איפה שהפונים יראו אותו: בטלפון. ואז לומדים לראות את אותו דבר בכרום, בלי טלפון ביד, לפעמים הבאות.

מה עושים עכשיו6 דקות
  • בטלפון: גוללים את כל העמוד. מחפשים טקסט שנחתך, כפתור שיוצא מהמסך, גלילה לצדדים, תמונה ענקית.
  • בכרום, על הקישור: Cmd+Option+I פותח את כלי המפתחים. הרבה קוד בצד, לא נוגעים. Cmd+Shift+M מציג את העמוד ברוחב טלפון.
  • יש בעיה? רושמים אותה במשפט: איפה, ומה רואים. זה השינוי הראשון שנעשה בשקף הבא.
  • סוגרים עם Cmd+Option+I.
מה בודקים
  • אין גלילה לצדדים
  • הכפתור בהירו נראה ולחיץ באצבע
  • התמונה שלך בהירו לא דוחפת את הכותרת מחוץ למסך
